## What to look for

- The problem and actual environment described in each project's README
- Source code, interfaces and system assumptions
- Evidence of testing or evaluation, distinguishing simulated examples from production validation
- How that approach could be adapted to another industry without assuming domain expertise before doing the research

*This page maps relevant portfolio work. It does not claim every project is deployed, independently retested, or that the same solution transfers unchanged to other industries.*
